# Imagens estáticas

Coloque aqui as imagens do site.

## 📸 Foto do autor (Francisco Gomes)

Para a sua foto aparecer na página Sobre, no Atendimento e na caixa de autor
dos posts, envie o arquivo com **exatamente este nome**:

```
autor-francisco-gomes.jpg
```

Caminho final: `public/images/autor-francisco-gomes.jpg`

Recomendações: foto quadrada (ex.: 400×400 px), boa iluminação, formato `.jpg`.
Enquanto o arquivo não existir, o site mostra um avatar com as iniciais "FG".
